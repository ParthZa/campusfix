# CampusFix

Campus Complaint Management System

## Features
- Student complaint submission
- Complaint tracking
- Admin dashboard
- Staff assignment
- Complaint status management
- Role-based access
- Image uploads
- Reports

## Technologies
PHP
MySQL
HTML
CSS
JavaScript
AJAX
